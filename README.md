## เกี่ยวกับโปรแกรม

โปรแกรมจองคิวร้านอาหารแบบ console ใช้สำหรับรับคิวลูกค้าและจัดลำดับการเรียกคิว โดยระบบจะแบ่งหมวดคิวตามจำนวนลูกค้าโดยอัตโนมัติ เพื่อให้ลูกค้ากลุ่มเล็กไม่ต้องรอโต๊ะเดียวกับลูกค้ากลุ่มใหญ่

| หมวด | จำนวนคน | ตัวอย่างเลขคิว |
|------|---------|----------------|
| A | 1–2 คน | A1, A2 |
| B | 3–4 คน | B1, B2 |
| C | 5 คนขึ้นไป | C1, C2 |

## ฟีเจอร์

| เมนู | หน้าที่ |
|------|---------|
| [1] New Queue | รับคิวใหม่ จัดหมวดและออกเลขคิวให้อัตโนมัติ |
| [2] Next Queue | เรียกคิวถัดไปของหมวดที่เลือก และอัปเดตไฟล์ |
| [3] All Queue | แสดงคิวทั้งหมดที่กำลังรออยู่ |
| [4] Cancel Queue | ยกเลิกคิวตามหมายเลขคิว |
| [0] Exit | ออกจากโปรแกรม |

นอกจากนี้ยังมีระบบ **Auto Sync** ซึ่งจะอ่านไฟล์คิวล่าสุดทุกครั้งที่เปิดโปรแกรม ทำให้คิวเดิมไม่หาย และเลขคิวรันต่อจากเดิมโดยไม่ซ้ำ

## ส่วนประกอบของโปรแกรม

| หัวข้อ | การนำไปใช้ในโปรแกรม |
|--------|---------------------|
| **OOP** | คลาสแม่ `QueueItem` เก็บข้อมูลคิว (เลขคิว ชื่อ เบอร์โทร จำนวนคน) และมีคลาสลูก `SmallQueue`, `MediumQueue`, `LargeQueue` สืบทอดจากคลาสแม่ โดยใช้ `super()` กำหนดตัวอักษร A/B/C หน้าเลขคิว |
| **Array** | ใช้ list 2 มิติ `queues = [[], [], []]` เก็บคิวแยกตามหมวด (แถว 0 = A, แถว 1 = B, แถว 2 = C) |
| **Function** | แยกแต่ละเมนูเป็นฟังก์ชัน ได้แก่ `new_queue()`, `next_queue()`, `all_queue()`, `cancel_queue()` และมีฟังก์ชันช่วย เช่น `get_zone()` สำหรับหาหมวดจากจำนวนคน |
| **Module** | แยกคลาสทั้งหมดไว้ในไฟล์ `queue_models.py` แล้วนำมาใช้ในไฟล์หลักด้วยคำสั่ง `import` |
| **File R/W** | `save_file()` บันทึกคิวลง `queue.txt` ทุกครั้งที่คิวเปลี่ยน และ `load_file()` อ่านคิวเดิมตอนเปิดโปรแกรม |
| **Try-except** | ป้องกันโปรแกรมหยุดทำงานเมื่อกรอกตัวอักษรในช่องตัวเลข หรือเมื่อยังไม่มีไฟล์ข้อมูล |

## วิธีใช้งาน

### 1. ติดตั้ง Python (ทำครั้งเดียว)
- ดาวน์โหลด Python ที่เว็บ [python.org/downloads](https://www.python.org/downloads/) แล้วติดตั้ง
- ตอนติดตั้งให้ติ๊กช่อง `Add python.exe to PATH` ด้วย

### 2. ดาวน์โหลดโปรแกรม
- กดปุ่มสีเขียว **`<> Code`** ด้านบนของ GitHub แล้วเลือก **Download ZIP**
- แตกไฟล์ ZIP ออกมา โดยไฟล์ `restaurant_queue.py` และ `queue_models.py` ต้องอยู่ในโฟลเดอร์เดียวกัน

### 3. เปิดใช้งาน
- **วิธีที่ 1:** ดับเบิ้ลคลิกที่ไฟล์ `restaurant_queue.py`
- **วิธีที่ 2:** หากดับเบิ้ลคลิกแล้วเปิดเป็นโปรแกรมอื่น ให้คลิกขวาที่ไฟล์ > **Open with** > เลือก **Python**

### 4. ตัวอย่างการใช้งาน

**จองคิว:** เลือกเมนู `1` แล้วกรอกชื่อ เบอร์โทร และจำนวนคน

```
=====Menu=====
[1] New Queue
[2] Next Queue
[3] All Queue
[4] Cancel Queue
[0] Exit
number: 1
==============
name: ต้น
phone: 0811111111
amount: 2
Queue NO: A1
```

**เรียกคิว:** เลือกเมนู `2` แล้วพิมพ์หมวดที่ต้องการเรียก (A, B หรือ C)

**ยกเลิกคิว:** เลือกเมนู `4` แล้วพิมพ์หมายเลขคิว เช่น `A1` (พิมพ์ตัวพิมพ์เล็กได้)
